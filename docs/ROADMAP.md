# ZORAX Development Roadmap

## Phase 0 — Toolchain validation
- [ ] Record exact CopperCube version/build.
- [ ] Confirm editor launches on Windows 8.1.
- [ ] Create, save, close, and reopen a blank scene.
- [ ] Run a minimal scene and record errors/performance.

## Phase 1 — Graybox prototype
- [ ] Create a small terrain arena.
- [ ] Add player spawn and third-person camera.
- [ ] Implement movement and collision.
- [ ] Add simple buildings, walls, and cover.
- [ ] Add one placeholder weapon and target dummy.

## Phase 2 — First original assets
- [ ] Review ZORAX Operator 01 model topology and proportions.
- [ ] Export and test a compatible model format.
- [ ] Prepare rig/animations if the model is not already rigged.
- [ ] Add one weapon and one loot crate.

## Phase 3 — Game systems
- [ ] Health, damage, elimination, and respawn test mode.
- [ ] Loot pickups and inventory prototype.
- [ ] Match timer and shrinking safe zone.
- [ ] Basic bots for offline testing.

## Phase 4 — Multiplayer feasibility
- [ ] Select networking/server stack after engine capability test.
- [ ] Build authoritative server prototype.
- [ ] Test 2 clients, then 4, 8, 16, and higher.
- [ ] Measure server CPU, memory, bandwidth, latency, and packet loss.
- [ ] Consider 50 players only after repeatable load tests.

## Phase 5 — Production and launch
- [ ] Final map art and optimization.
- [ ] Account, progression, cosmetics, and secure economy.
- [ ] Anti-cheat and moderation plan.
- [ ] Closed testing, crash reporting, and staged release.
- [ ] Hosting, support, privacy, and monetization readiness.
